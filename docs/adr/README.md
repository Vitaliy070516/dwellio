# Architecture Decision Records

Кожне значуще архітектурне рішення фіксуємо окремим файлом `NNN-коротка-назва.md`.
Рішення не переписуємо: якщо воно змінилось, пишемо новий ADR зі статусом «замінює ADR-NNN».
