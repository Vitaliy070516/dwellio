## Definition of Done по тижнях

1. **Тиждень 1:** `make ci` зелений; пошук і генерація працюють локально (Ollama/Fake); ADR-001…004.
2. **Тиждень 2:** MVP можна показати з локальної машини через тунель (напр. Cloudflare Tunnel); rate limit + токени в Redis; OpenAPI/Swagger UI; README v1.
3. **Тиждень 3:** акаунт AWS за чеклистом, застосунок працює на EC2 за Elastic IP; дашборд Grafana з метриками й логами Loki; push у `main` → деплой; GitLab-пайплайн еквівалентний; бекап `pg_dump` у S3 з перевіреним restore.
4. **Тиждень 4:** `kubectl apply -k overlays/local` піднімає стек у k3d; HPA масштабується під навантаженням (k6/Locust); результати в `docs/`.
5. **Тиждень 5:** список знахідок `[review]`/`[qa]` закритий або занесений у known issues; Architecture tests покривають межі модулів.
6. **Тиждень 6:** SLO/SLI та 100× у README; `terraform destroy` виконано; 5-хвилинне демо та шпаргалка до співбесіди.

## Ризики й залежності

- **AWS:** чеклист безпечного старту — в `docs/architecture.md`, розділ 4. Акаунт створюємо на тижні 3 (рішення зафіксовано), тому кредити не горять під час розробки MVP. У тижні 2 демо — локально через тунель, перший деплой на AWS — у тижні 3.
- **Ресурси WSL2 (16 ГБ):** observability та Ollama — тільки через Compose `profiles`.
- **Scope creep:** якщо тиждень 2 затягується, KEDA (тиждень 4) і частина observability — перші кандидати на відкладення.
